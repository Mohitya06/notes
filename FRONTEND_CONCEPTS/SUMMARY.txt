💡 KEY CONCEPTS EXPLAINED:

   STORAGE DECISION TREE:
   • Need persistent? → localStorage
   • Need session-only? → sessionStorage
   • Need auth/tracking? → Cookies
   • Need large data? → IndexedDB

   AUTH FLOW:
   1. Login → Server validates → Returns JWT
   2. Client stores JWT (secure storage)
   3. Send JWT with requests
   4. JWT expires → Use refresh token
   5. Get new JWT → Continue using

   STATE MANAGEMENT CHOICE:
   • Simple app? → Context API
   • Complex app? → Redux / Zustand
   • Reactive? → MobX / Recoil
   • Learning? → Context API first

   API CALLING:
   • Simple? → Fetch API
   • Complex? → Axios (interceptors, retries)
   • GraphQL? → Apollo Client
   • Real-time? → WebSockets
