## ❓ FAQ: How to Use This Guide

**Q: Should I read all files?**
A: For 4-week prep: Yes, but prioritize Levels 1-3 first.
For 1-week prep: JavaScript L1 + React L2&3 + Node L1&2 + DSA + 1 project.

**Q: Can I skip JavaScript if I know React?**
A: JavaScript Level 3 is ESSENTIAL. React depends on advanced JS concepts.

**Q: Should I read sequentially?**
A: Levels should be sequential (1→2→3), but you can do multiple files in parallel.
Example: JavaScript L1 in morning, React L1 in afternoon.

**Q: How much time per file?**
A: Level 1: 2-3 hours | Level 2: 3-4 hours | Level 3: 2-3 hours

**Q: Which file is hardest?**
A: JavaScript Level 3 and DSA Algorithms (most concepts)

**Q: Which file is most important?**
A: JavaScript Level 2-3 (foundation of all web development)

**Q: Should I code along?**
A: YES! Absolutely. Type out every code example.

**Q: How many times should I read each file?**
A: Level 1: 1-2 times | Level 2: 2-3 times | Level 3: 3+ times
